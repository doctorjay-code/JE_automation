# JE automation

네 가지 업무 도구를 **창 하나**로 합친 프로그램입니다.

| 탭 | 하는 일 | 원래 도구 |
|---|---|---|
| **운용지시대장** | 날인본 PDF 파일명을 읽어 지시대장 엑셀 C열에 자동으로 채웁니다 | 운용지시대장_자동반영도구 v1.0.4 |
| **자금판** | 지시내역을 자금판 엑셀에 자동으로 반영합니다 | 자금판_자동반영도구 v1.0.3 |
| **합계검증** | 자금판 잔액을 모아 수탁사별로 합산합니다 | 합계검증 v1.0.0 |
| **BGC 레포** | 레포 거래내역서 PDF를 읽어 자금판에 매수·환매를 반영합니다 | BGC_Repo_자동반영도구 |

> 네 도구의 기능은 그대로이고, 화면과 설정만 하나로 정리했습니다.
> **BGC 레포**는 Outlook 연동을 빼고 폴더 스캔 방식만 담았습니다.
> 자세한 변경 내용은 담당자에게 문의하세요.

---

## 1. 실행 방법

전달받은 **zip 파일의 압축을 먼저 풉니다.** (압축 상태로는 실행되지 않습니다)
풀린 폴더 안의 `JE_automation.exe` 를 더블클릭합니다.
Python이나 엑셀 프로그램이 설치되어 있지 않아도 실행됩니다.

> **폴더째로 두고 쓰세요.** exe만 따로 꺼내면 실행되지 않습니다.
> 폴더 안 `_internal` 폴더에 필요한 파일이 들어 있습니다.

**처음 실행할 때 파란 경고창이 뜰 수 있습니다.**
`Windows의 PC 보호` → **추가 정보** → **실행** 을 누르면 됩니다.
(인터넷에서 받은 프로그램에 붙는 정상 안내입니다)

| 주의 | 이유 |
|---|---|
| **바탕화면이나 문서 폴더**에 풀어주세요 | `C:\Program Files` 처럼 쓰기가 막힌 곳에 두면 설정이 저장되지 않습니다 |
| exe 옆에 설정 파일이 생깁니다 | `JE_automation_settings.json` — 지우면 설정이 처음 상태로 돌아갑니다 |
| 폴더 이름·위치는 바꿔도 됩니다 | 단, 폴더 안 파일 구성은 그대로 두세요 |

## 2. 자동 업데이트

**처음 한 번만 zip 파일을 받아 풀어두면, 그 뒤로는 exe를 실행하기만 하면 됩니다.**
새 버전이 나오면 프로그램이 알아서 물어보고, 업데이트하면 바로 교체됩니다.

### 동작 방식

| 순서 | 일어나는 일 |
|---|---|
| 1 | exe를 켜면 잠시 뒤 GitHub를 확인합니다. (몇 초) |
| 2 | 새 버전이 있으면 `새 버전(1.2.0)이 나왔습니다. 지금 업데이트할까요?` 창이 뜹니다. |
| 3 | `예` 를 누르면 진행 표시줄이 나오면서 내려받습니다. |
| 4 | 프로그램이 **스스로 종료되고**, 별도 작업 프로그램이 파일을 교체합니다. |
| 5 | **새 버전이 자동으로 다시 켜집니다.** |

### 알아두실 것

| 항목 | 내용 |
|---|---|
| **변경 이력** | 탭 줄 오른쪽 **[변경 이력]** 을 누르면 버전별로 뭐가 바뀌었는지 볼 수 있습니다. 업데이트 확인 창에도 이번에 바뀐 내용이 함께 표시됩니다. |
| 설정은 그대로입니다 | `JE_automation_settings.json` 은 업데이트해도 **지워지지 않습니다.** (지정한 폴더·매핑 그대로) |
| 바로가기는 그대로입니다 | 예전에 만든 바탕화면 바로가기가 계속 동작합니다. |
| 안 물어보게 하려면 | `예` 대신 `아니오` 를 누르면 그날은 묻지 않습니다. (다음에 다시 켤 때 다시 묻습니다) |
| 인터넷이 안 되면 | 조용히 넘어갑니다. **기존 프로그램이 그대로 동작합니다.** |
| 교체에 실패하면 | 기존 exe 가 그대로 남아 있어 프로그램은 계속 켜집니다. |
| 내려받는 크기 | **약 5MB** (프로그램 본체만 바뀔 때). 라이브러리까지 바뀐 버전만 29MB |
| exe 이름은 고정입니다 | `JE_automation.exe` — 업데이트해도 이름이 바뀌지 않습니다. (바로가기가 깨지지 않고, exe 가 쌓이지도 않습니다) |
| 버전 확인 | 창 제목에 표시됩니다. (예: `JE automation  v1.1.6`) exe 속성 → 자세히 에도 나옵니다 |

> **업데이트 중에는 프로그램이 잠시 꺼졌다가 다시 켜집니다.** (10초 안팎)
> excel 문서를 열려 있다면 먼저 닫아두세요.
>
> 업데이트해도 **폴더 이름과 exe 이름은 그대로**입니다. (창 제목만 새 버전으로 바뀝니다)

## 3. 화면 읽는 법

### 탭

- 위쪽 탭을 누르면 아래 화면이 바뀝니다. 새 창이 열리지는 않습니다.
- `Ctrl+Tab` / `Ctrl+Shift+Tab` 으로도 이동합니다.
- **탭을 좌우로 끌면 순서가 바뀌고, 그 순서가 저장됩니다.**
- 오른쪽 위 **X 하나로 프로그램 전체**가 꺼집니다.

### 버튼 규칙

| 생김새 | 뜻 |
|---|---|
| 파란 버튼 | 그 화면의 **주요 동작** (스캔, 전체 반영) |
| 흰 버튼 | 보조 동작 (찾아보기, 전체 선택, 취소) |

### 맨 아래 상태 표시줄

화면 맨 아래 한 줄에 진행 상황이 나옵니다.

- 왼쪽: 지금 무슨 일을 하는지, 또는 폴더가 잘못됐다는 안내
- 오른쪽: 건수·합계 같은 요약

## 4. 운용지시대장 탭

### 사용 순서

1. **지시대장 엑셀** — `찾아보기` 로 운용지시대장 엑셀을 고릅니다.
2. **PDF 상위폴더** — `찾아보기` 로 날인본 PDF가 모여 있는 폴더를 고릅니다.
3. **스캔** — 하위의 `날인본` 폴더를 모두 찾아 PDF 목록을 만듭니다.
4. 목록에서 넣을 항목을 확인합니다. `확인요망` 은 더블클릭해 시트를 직접 고를 수 있습니다.
5. **전체 반영** 또는 **선택만 반영** 을 누릅니다.

### 반영기간

`반영기간 [시작] ~ [끝]` 에 날짜를 넣고 **[기간 적용]** 을 누르면 그 기간만 대상이 됩니다.
`2026-07-01`, `20260701`, `2026.7.1` 모두 됩니다. 비우면 전체 기간입니다.

### 기억해 둘 것

- **C열(내용)** 에만 넣습니다. B열(일자), D열(기안문서번호)은 건드리지 않습니다.
- 이미 들어있는 값은 `이미 반영됨` 으로 표시되고 자동으로 빠집니다.
- 폴더와 시트를 한 번 연결하면 **폴더 단위로 기억**됩니다.

## 5. 자금판 탭

### 사용 순서

1. **자금판 폴더** — 자금판 엑셀들이 있는 폴더를 고릅니다.
2. **지시내역 폴더** — 운용지시내역 엑셀이 있는 폴더를 고릅니다.
3. **스캔** — 여기서 목록이 나옵니다.
4. **지시내역 파일** — 여러 개면 목록에서 고릅니다. 고르면 바로 읽습니다.
5. 표에서 반영할 항목을 확인합니다.
6. **전체 반영** 또는 **선택만 반영** 을 누릅니다.

> **스캔을 눌러야 목록이 나옵니다.**
> 폴더를 바꿨는데 목록이 그대로면, 상태 표시줄에 `스캔을 눌러주세요` 라고 나옵니다.

### 표에서 고칠 수 있는 것

| 열 | 더블클릭하면 |
|---|---|
| 자금판 작성 내용 | 적요 문구를 직접 고칩니다 |
| 매칭된 자금판 파일 | 그 엑셀 파일이 열립니다 |
| 매칭 여부 | 자금판 엑셀을 직접 골라 연결합니다 |
| 반영 여부 | 개별 반영 / 반영 취소(되돌리기) |

### 사유 매핑

`사유 매핑 설정` 에서 `사유 → 자금판 적요` 규칙을 추가·수정·삭제할 수 있습니다.
같은 사유라도 `대상기관/항목` 이 다르면 다른 적요로 보낼 수 있습니다.
(예: 가격정보비용 → A평가기관 / B평가기관)

## 6. 합계검증 탭

### 사용 순서

1. **자금판 폴더** — 자금판 파일들이 있는 폴더를 고릅니다.
2. **`엑셀 열고 저장·닫기` 체크** — 아래 설명을 꼭 읽어보세요.
3. **스캔** — 하위폴더를 모두 뒤져 이름에 `자금판` 이 들어간 엑셀을 찾습니다.
4. 표에서 펀드별 시트·셀·수탁사를 확인합니다. 틀린 칸은 더블클릭해 고칩니다.
5. 위쪽에 수탁사별 합계와 `원화 전체 합계` 가 표시됩니다.

### 수탁사 관리 — 추가 / 수정 / 삭제

수탁사 이름은 **프로그램에 박혀 있지 않습니다.** 전부 설정 파일에 저장되고,
화면의 **[수탁사 관리]** 버튼에서 직접 관리합니다.

| 하고 싶은 것 | 방법 |
|---|---|
| **추가** | 아래 칸에 이름을 입력하고 **[추가]** |
| **이름 수정** | 목록에서 그 수탁사를 고르면 → 아래 칸에 이름이 들어옵니다. 고친 뒤 **[수정]** |
| **삭제** | 목록에서 고르고 **[삭제]** (또는 키보드 `Delete`) |

- **처음에는 목록이 비어 있습니다.** 아래 칸에 이름을 입력해 하나씩 추가하세요.
- **이름을 수정하면, 그 수탁사를 쓰던 파일들도 새 이름으로 자동 변경됩니다.**
- **삭제할 때 그 수탁사를 쓰는 파일이 있으면** 미리 알려주고,
  확인하면 그 파일들의 수탁사는 `비움` 이 됩니다.
- 한 번 넣은 수탁사는 **다음에 켜도 그대로** 남아 있습니다.

> 수탁사가 하나도 없으면 합계 칸 자리에
> `수탁사가 없습니다 · [수탁사 관리]에서 추가하세요` 라고 안내가 나옵니다.

### 합계 칸 (네모) — 반올림 & 클릭 복사

- 합계는 **소수점 첫째자리에서 반올림**해 정수로 표시합니다. (예: `500.5` → `501`)
- **네모칸을 누르면 그 값이 복사됩니다.** 엑셀에 붙여넣기 하면 됩니다.
- 복사되는 값은 **화면에 보이는 그대로**입니다. 3자리 쉼표도 함께 복사됩니다. (예: `1,235,568`)
- 복사되면 맨 아래 상태 표시줄에 `복사됨: 1,235,568` 이 뜹니다.
- 값이 `-` 인 칸은 복사할 것이 없어서 `복사할 값이 없습니다` 라고 나옵니다.

> **엑셀에 붙일 때**: 쉼표가 있으면 엑셀이 **글자로** 인식할 수 있습니다.
> 숫자로 넣으려면 붙여넣은 뒤 셀에서 `Ctrl+Shift+1` 을 누르거나,
> `홈 → 표시 형식 → 숫자` 를 고르세요.

### `엑셀 열고 저장·닫기` — 이게 제일 중요합니다

자금판 파일에 저장된 숫자는 **마지막으로 저장할 때 계산된 값**입니다.
그 뒤로 잔액이 바뀌었어도 파일 안 숫자는 그대로입니다.
엑셀로 열면 그때 다시 계산되고, **저장을 해야 그 결과가 파일에 남습니다.**

| 체크 | 동작 | 걸리는 시간 |
|---|---|---|
| **켜짐** | 엑셀을 띄워 파일마다 **열기 → 값 읽기 → 저장 → 닫기** | 파일 20개 기준 10~40초 |
| **꺼짐** | 엑셀을 안 쓰고 **저장된 값만** 읽음 | 1~2초 |

- 켜져 있으면 **최신 값**을 읽습니다. 대신 엑셀을 실제로 저장하므로 **원본 파일이 바뀝니다.**
- 꺼져 있으면 빠르지만, 파일에 저장된 **옛날 값**일 수 있습니다.
- 두 값을 한 번 비교해보고, 똑같으면 앞으로는 꺼두고 쓰셔도 됩니다.

> 엑셀이 이미 열려 있는 파일은 그 창을 잡아서 저장하고 닫습니다.
> **아무도 안 쓰는 시간대에** 돌리세요.

## 7. BGC 레포 탭

레포 거래내역서 PDF를 읽어서, 해당 펀드의 자금판에 **REPO매수 / REPO환매** 두 줄을 넣습니다.

### 사용 순서

1. **자금판 폴더** — 자금판 엑셀들이 있는 폴더를 고릅니다.
2. **PDF 폴더** — 레포 거래내역서 PDF가 있는 폴더를 고릅니다.
3. **스캔** — PDF를 읽어 표에 채웁니다.
4. 표에서 펀드코드·매수일·환매일·금액·매칭된 자금판을 확인합니다.
5. **엑셀에 반영** 을 누릅니다.

### PDF는 어떻게 모으나요

| 방법 | 설명 |
|---|---|
| 직접 넣기 | 받은 PDF를 PDF 폴더에 복사한 뒤 [스캔] |
| Outlook 규칙 | Outlook에서 `레포 거래내역서` 메일의 첨부파일을 **지정 폴더로 자동 저장**하게 설정해 두면, [스캔]만 누르면 됩니다 |

> 이 탭에는 **Outlook 연동이 없습니다.** (원본 도구에서 제외)
> 메일 검색·다운로드·무인 자동 실행은 지원하지 않습니다.

### 표 읽는 법

| 열 | 뜻 |
|---|---|
| PDF 파일 | 읽은 PDF 이름 |
| 펀드코드(PDF) | PDF에서 뽑은 자산코드 (예: `12345ZZ`) |
| 매수일 / 환매일 | PDF에서 뽑은 날짜 |
| 개시금액(매수) / 계(환매) | 반영될 금액 |
| 매칭 자금판 | 짝이 맞는 자금판 파일 |
| 상태 | 추가됨 / 이미 있음(건너뜀) / 매칭 실패 |

### 주의

- **자금판 원본 엑셀에 바로 저장**합니다. 자동 백업은 없습니다.
- 같은 일자·적요·금액이 이미 있으면 **자동으로 건너뜁니다.** (중복 입력 방지)
- 매칭 실패가 나오면 그 PDF의 펀드코드와 자금판 파일명을 확인하세요.

## 8. 설정 파일

exe 옆에 `JE_automation_settings.json` **한 개**가 생깁니다.

```json
{
  "공통":        { "window_geometry": "...", "last_tab": "자금판", "tab_order": ["..."] },
  "운용지시대장": { ... },
  "자금판":      { ... },
  "합계검증":    { ... },
  "BGC Repo":   { "target_folder": "...", "last_pdf_folder": "..." }
}
```

- 기능별로 구역이 나뉘어 있어서, 한 기능의 설정만 초기화할 수 있습니다.
- **저장된 폴더 경로는 프로그램이 마음대로 바꾸지 않습니다.**
  다른 컴퓨터의 경로가 들어 있어도 그대로 둡니다. (그 경로가 없으면 안내만 표시)
- 예전 프로그램의 설정 파일(`운용지시대장_자동반영도구_설정.json` 등)을
  exe 옆에 같이 두면 **처음 한 번만** 자동으로 가져옵니다.
- **자동 업데이트를 해도 이 설정 파일은 지워지지 않습니다.** (백업 후 되돌립니다)

## 9. 주의 — 자동 백업 없음

네 기능 모두 **원본 엑셀에 바로 저장**합니다. 자동 백업 기능은 없습니다.

| 상황 | 권장 조치 |
|---|---|
| 처음 돌려보는 경우 | 엑셀 파일을 미리 복사해 두고 **사본으로 먼저 테스트**하세요. |
| 대량으로 반영하는 경우 | 작업 전에 폴더째로 백업해 두세요. |
| 잘못 들어간 경우 | 엑셀에서 해당 행을 직접 지우면 됩니다. (프로그램이 기존 행을 지우지는 않습니다) |
| 자금판 반영을 되돌리려면 | 표의 `반영 여부` 를 더블클릭하면 개별 취소가 됩니다. |

자금판의 반영·취소는 **일자, 적요, 금액, 입출금 구분**을 함께 보고 판정합니다.
같은 날짜·금액이라도 적요가 다르면 다른 거래로 안전하게 구분됩니다.

## 10. 다른 컴퓨터에 배포할 때

**`JE_automation.zip` 하나만** 보내면 됩니다. Python 설치 필요 없습니다.

| 항목 | 내용 |
|---|---|
| zip 이름 | `JE_automation.zip` — 버전이 바뀌어도 **이름 그대로** |
| 안에 든 것 | exe + `_internal` + **설정 파일** |
| 받는 사람이 할 일 | 압축 풀고 → `JE_automation.exe` 실행 (끝) |

설정이 들어 있어서 받는 사람이 **폴더·수탁사를 하나도 지정하지 않아도** 바로 씁니다.

| 하면 안 되는 것 | 이유 |
|---|---|
| **exe만 따로 꺼내서 주기** | 폴더 안 `_internal` 이 없으면 실행되지 않습니다 |
| **zip을 풀지 않고 실행** | 압축 상태로는 실행되지 않습니다 |

> **두 번째 배포부터는 zip을 줄 필요가 없습니다.**
> 받는 사람이 exe를 켜면 새 버전을 알아서 받습니다. (첫 zip 한 번만 넘기면 끝)

> **다른 사람에게 줄 일이 생기면** 먼저 알려주세요.
> 지금 zip 에는 **내 설정(폴더 경로)이 들어 있어서**, 그 사람 컴퓨터에서는 엉뚱한 경로가 뜹니다.
> 설정을 뺀 zip 을 따로 만들어 드립니다.

> **백신이 바이러스로 잡을 때**
> 이 프로그램은 서명이 없는 업무용 도구라 백신이 오해할 수 있습니다.
> 회사 PC라면 IT에 파일을 보내 **예외(화이트리스트) 등록**을 요청하는 것이 가장 확실합니다.

## 11. 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 파란 경고창이 뜬다 | `추가 정보 → 실행` (정상 안내입니다) |
| 설정이 저장되지 않는다 | exe를 `Program Files` 같은 곳에 두지 않았는지 확인 |
| 자금판 목록이 안 나온다 | **스캔**을 눌렀는지 확인 |
| 폴더가 없다고 나온다 | 그 경로가 이 컴퓨터에 있는지 확인 (다른 PC 경로일 수 있습니다) |
| 화면이 하얗게 변한다 | 그 탭만 문제입니다. 다른 탭은 그대로 쓸 수 있습니다 |
| 새 버전 알림이 안 뜬다 | 인터넷 연결을 확인하세요. (안 되면 조용히 넘어갑니다) |
| 업데이트 도중 프로그램이 안 켜진다 | exe를 직접 더블클릭해 실행하세요. (이전 버전이 남아 있습니다) |
| 원인을 모르겠다 | exe 옆 `JE_automation_error.log` 파일을 담당자에게 보내주세요 |
